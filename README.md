# writzx's Dorion Tap

## What is Dorion?

Dorion is an alternative Discord client aimed towards lower-spec or storage-sensitive PCs that supports themes, plugins, and more!

You can [find out more information here](https://github.com/SpikeHD/Dorion).

## How do I install Dorion via Homebrew?

`brew install writzx/dorion/dorion`

Or `brew tap writzx/dorion`, then `brew trust writzx/dorion` and then `brew install --cask dorion`.

Or, in a [`brew bundle`](https://docs.brew.sh/Brew-Bundle-and-Brewfile) `Brewfile`:

```ruby
tap "writzx/dorion", trusted: true
cask "writzx/dorion/dorion", trusted: true
```
